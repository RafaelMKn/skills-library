## ⚙️ Como Utilizar

### 1. Claude Code
Crie links simbólicos / junctions para a pasta `.claude/skills/`:
```powershell
# Exemplo para uma skill específica:
New-Item -ItemType Junction -Path ".claude/skills/n8n-flow-builder" -Target "skills-library/01-automacao-n8n-make/n8n-flow-builder"
```

### 2. Antigravity & Codex
Aponte via `.agents/skills/` ou importe diretamente no arquivo de configuração do seu projeto.
